# Travel Product Optimization Dashboard

Travel Analyst helps travel teams understand package performance and prioritize product improvements using bookings, revenue, satisfaction, conversion, and value scores.

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express

## Mock UX Design

[View the interactive Mock UX](./docs/mock-ux.html)

This interactive prototype maps the dashboard-to-decision journey: review portfolio signals, filter and compare packages, explore a recommendation, and save a next step.
