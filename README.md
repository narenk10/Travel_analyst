# Travel Product Optimization Dashboard

Travel Analyst helps travel teams understand package performance and prioritize product improvements using bookings, revenue, satisfaction, conversion, and value scores.

## Project idea

Build a dashboard that turns travel-package performance data into clear, actionable opportunities. Users can review portfolio-level trends, filter and compare packages, investigate an opportunity, and record a next step. The goal is to help travel teams decide which products to improve and why.

## Five-day capstone plan

| Day | Plan |
| --- | --- |
| Day 1 | Confirm the problem, target users, project scope, success measures, and initial package data. Set up the project repository and task board. |
| Day 2 | Define the data model and implement the backend endpoints for package and portfolio analytics. |
| Day 3 | Build the dashboard interface, including portfolio metrics, package filters, and comparison views. |
| Day 4 | Connect the frontend to the analytics endpoints, test key user flows, and refine the opportunity details and next-step experience. |
| Day 5 | Fix remaining issues, document setup and project decisions, prepare a demo, and review the work against the success measures. |

## Stack

- Frontend: React + Vite
- Backend: Node.js + Express
